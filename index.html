What is CTSI staking?

CTSI holders lock tokens on Ethereum mainnet to produce blocks on Noether, Cartesi's sidechain. Producers earn CTSI from the Mine Reserve.

  • Every stake, block claim, and reward is an on-chain Ethereum transaction
  • The Noether node is off-chain software that watches PoS contracts and submits produceBlock() when eligible
  • Noether blocks are empty today — the sidechain is a reward mechanism, not an app execution environment

Distinct from Cartesi Rollups (application logic in the Cartesi Machine).

How block production works

  1. Stake CTSI via StakingImpl
  2. Weighted random selection — higher stake = higher probability
  3. Eligible staker's worker (Noether node) calls produceBlock()
  4. RewardManager pays ~2,900 CTSI to the staker
  5. Difficulty adjusts to keep block interval stable as total stake changes

Three ways to participate

1. Public pool

Deposit CTSI → receive shares. Operator runs node. Rewards auto-compound; operator takes commission.

explorer.cartesi.io → Stake

2. Private node

Stake directly + run your own Noether node as worker. You fund node ETH for gas.

explorer → Node Runners → Create My Node

3. Custodial

CEX / custodian (Binance, etc.) — outside the open-source PoS stack. Own rules and custody.

What does a node runner need to get started?

Staker (owner)

Holds staked CTSI. Receives CTSI rewards.

Example: your MetaMask wallet, or the pool contract

Worker (node)

Authorized agent that submits produceBlock(). Spends ETH gas.

Example: Noether node's wallet (auto-created on first run)

How can I test the staking system?

Sepolia testnet

  1. Get Sepolia ETH + test CTSI (ask Cartesi on Discord)
  2. Run Noether against Sepolia RPC (Infura / Alchemy URL in Docker --url)
  3. Open explorer.cartesi.io — switch MetaMask to Sepolia
  4. Stake, hire your node (copy address from starting worker 0x… log), produce blocks

Same flows as mainnet; no real money.

Local Hardhat (chain 31337)

  1. staking-pool or pos-dlib → yarn start (Hardhat on :8545, deploys contracts)
  2. noether → yarn start --account-index 1 (worker on account 1)
  3. pos-dlib → worker:hire, pos:create, fund RewardManager, pos:stake
  4. Optional full stack: Graph node + subgraph + explorer yarn dev (MetaMask → localhost:8545, chain 31337)

Fast iteration; reset Hardhat wipes chain state.

Audits & security

  • CertiK (Sep 2021) — staking-pool contracts; 14 findings, 0 critical
  • Internal / advisor review before mainnet beta
  • Immunefi bounty (up to $500k) — program URL may be stale
  • PoS v2 (Nov 2022) — no separate public audit found

Node compromise: attacker can only steal node wallet ETH, not staked CTSI. CTSI controlled by staker wallet only.
